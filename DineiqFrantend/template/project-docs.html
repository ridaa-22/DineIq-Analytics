Project Docs / README

DineIQ Admin Panel

A restaurant operations dashboard for managing menu items, live orders, dine-in tables, analytics, reports and customer segments.

Pages
  • index.html — Overview / Dashboard: revenue, order status, messages, to-do, visitor map.
  • menu-management.html — Add, edit and track menu items, stock and pricing.
  • operations-orders.html — Live order tracking from kitchen to delivery.
  • data-tables.html — Dine-in floor plan and table status.
  • analytics-ml.html — ML model registry and forecast accuracy.
  • reports.html — Build and download operational reports.
  • customer-segments.html — Customer segmentation and top-spender list.
  • project-docs.html — This page.
Setup

1. Keep all pages in the same folder as index.html so the shared assets/ folder resolves.

2. Every page checks localStorage.authToken and redirects to login.html if missing.

3. The sidebar highlights the current page automatically based on file name.

Tech Stack

Bootstrap-based admin template (vendor bundle in assets/vendors), vanilla JS for auth guard and logout, MDI icon set.

Notes

All data shown across these pages (orders, customers, models, reports) is placeholder/sample data — wire up your API endpoints in place of the static tables to go live.
